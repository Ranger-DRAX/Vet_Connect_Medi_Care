# Vet Connect Medi Care 🏥🐾

A comprehensive veterinary healthcare management system that connects pet owners with veterinary services through an intuitive web platform.

## 📋 Overview

Vet Connect Medi Care is a full-stack web application designed to streamline veterinary healthcare services.  The platform facilitates appointment scheduling, medical record management, and communication between pet owners and veterinary professionals.

## 🏗️ Project Structure

```
Vet_Connect_Medi_Care/
├── frontend/          # React-based frontend application
├── backend/           # Backend server and API
├── instruction. md     # Git workflow instructions
├── package.json       # Root package configuration
└── LICENSE           # MIT License
```

## 🚀 Technology Stack

### Frontend
- **React. js** - UI framework
- **JavaScript** - Primary programming language
- Created with Create React App for optimal setup

### Backend
- Node.js backend server
- RESTful API architecture

## 📦 Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager
- Git

### Clone the Repository
```bash
git clone https://github.com/Ranger-DRAX/Vet_Connect_Medi_Care.git
cd Vet_Connect_Medi_Care
```

### Install Dependencies

#### Frontend Setup
```bash
cd frontend
npm install
```

#### Backend Setup
```bash
cd backend
npm install
```

## 🎯 Running the Application

### Start Frontend Development Server
```bash
cd frontend
npm start
```
The frontend will run on [http://localhost:3000](http://localhost:3000)

### Start Backend Server
```bash
cd backend
npm start
```

## 🔧 Available Scripts

### Frontend Scripts

#### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

#### `npm test`
Launches the test runner in interactive watch mode

#### `npm run build`
Builds the app for production to the `build` folder

#### `npm run eject`
⚠️ **One-way operation** - Ejects from Create React App for full configuration control
